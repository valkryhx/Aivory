# 邮箱域自动加入工作空间

平台管理员在独立的 `/admin/domains` 页面管理邮箱域规则。工作空间创建与负责人更换在 `/admin/workspaces` 页面完成。

## 配置顺序

1. 在 `/admin/workspaces` 点击“创建工作空间”，填写名称，按姓名或邮箱搜索一个已启用的账号作为管理员。该账号自动成为空间成员、所有者及管理员。被锁定到其他工作空间的账号不能担任新空间负责人。
2. 在 `/admin/domains` 点击“添加域规则”，填写一个或多个 `example.com` 形式的邮箱域，选择工作空间，并设置密码注册是否需要邮箱验证、注册后的初始用户组、是否允许购买订阅及是否锁定个人空间。规则创建后立即启用自动加入。
3. 在该规则的“域用户”中，平台管理员可以添加任意尚未绑定其他域规则的正常或待验证账号，不要求账号邮箱匹配规则；也可以移除成员，或选择“遵循域规则”“仅工作空间”“允许个人空间”。

## 生效范围

- 一条规则可配置最多 50 个匹配域名，每个域名只能属于一条规则。系统精确匹配邮箱最后一个 `@` 后的域名且不区分大小写；`example.com` 不匹配 `sub.example.com`。不接受邮箱地址、URL、通配符或尾部句点；国际化域名使用 Punycode。
- 编辑匹配域名列表只影响后续注册和验证策略匹配，不会解除已经绑定到该规则的成员。规则的目标工作空间创建后仍不可更换。
- 自动加入只作用于规则启用后创建的非平台管理员账号，不会在创建规则时直接追溯已有账号；管理员可以在域用户页面手动筛选并加入历史账号。
- 密码注册是否需要邮箱验证码由全局设置和命中的域规则共同决定：任一处开启都必须验证；两处都关闭时直接完成注册登录。域规则暂停后不再影响新注册账号。
- OAuth 第三方注册登录不要求 Aivory 邮箱验证码，即使全局或域规则要求验证也会直接激活账号。只要第三方返回的邮箱命中已启用的企业域规则，包括通用 OAuth2，账号也会按规则自动加入工作空间、应用个人空间限制并进入规则指定的初始用户组。已有邮箱账号的自动合并仍只接受可信且已验证的提供商邮箱，避免第三方声明覆盖现有身份。
- 域规则可选择一个注册后的初始用户组。留空时使用系统默认用户组；选择后，密码注册和第三方登录创建的新账号都会在同一建号事务中进入该组。规则暂停时不会对新账号应用工作空间、锁定或初始用户组策略。
- 账号创建、域绑定和工作空间成员关系在同一个数据库事务中完成。任一环节失败都会回滚。
- 域用户绑定保存于账号，不依赖其之后的邮箱值，因此修改邮箱不会解除限制。

## 订阅购买

“允许购买订阅”默认开启，升级后的已有规则也保持允许。关闭后，该规则已绑定用户的 `/subscription` 页面仅显示当前用户组卡片；套餐列表、积分包、兑换入口和支付记录均隐藏。当前用户组即使未公开展示，所属用户仍能查看其卡片。

服务端同时拒绝创建支付订单和继续支付请求。此策略独立于个人空间锁定，暂停自动加入不会解除现有成员的购买限制；重新允许购买或移除域绑定后恢复正常。已支付订单的履约不受影响。

初始用户组下拉列表顶部支持按名称或 ID 搜索，支持键盘选择，并保留“系统默认用户组”选项。选择只影响后续注册的初始分组。

## 个人空间锁定

开启后，遵循域规则的用户只能使用指定工作空间，不能切换到个人空间或其他空间、创建新空间、通过邀请加入其他空间或退出当前空间。服务端会拒绝个人资源请求及伪造工作空间参数的请求。前端禁用个人空间选项并标示锁定；直接打开个人文件页会返回工作空间首页。

锁定个人空间不会直接禁用隐私对话。隐私对话按系统用户组和指定工作空间的开关共同判断，两层都允许时显示入口；关闭任一开关时隐藏入口并拒绝请求。隐私请求不能借此切换到其他空间，详见 [隐私对话](private-chat.md)。

个人空间数据保留。管理员可以统一关闭域规则的锁定，也可以单独将用户设置为“允许个人空间”；解除后原有个人空间数据可再次访问。个别用户的显式权限不随域级开关改变，选择“遵循域规则”后才恢复继承。

权限按请求从数据库读取，无需重新登录。规则和用户权限更新会通知在线客户端，并撤销旧权限下的生成及上传权限快照。

若用户在解除限制期间退出过指定空间，管理员重新施加锁定时会恢复其成员关系，保证仍有可进入的空间。

普通工作空间成员管理仍不能直接移出被锁定到该空间的域成员。平台管理员应在域管理中执行“移除成员”，由系统在同一事务中先解除域绑定，再按成员关系来源决定是否移出工作空间。

## 手动管理成员

在域规则的“域用户”弹窗中点击“添加成员”，可以按姓名或邮箱搜索并选择任意尚未绑定域规则的正常或待验证账号，账号邮箱不需要匹配规则中的域名。候选列表排除平台管理员、已停用账号和已经绑定其他域规则的账号，并显示每个账号尚在个人空间中的对话数量。每次搜索最多显示并加入 500 个账号。

手动加入会在同一个事务内创建域绑定和工作空间成员关系，任一账号校验失败时整批回滚。账号原有的系统用户组保持不变；域规则中的“初始用户组”只用于规则命中后的新账号注册，不覆盖手动添加账号的用户组。停止自动加入不影响管理员手动添加成员。

平台管理员可以随时从域规则移除单个成员。移除会解除域绑定和个人空间限制；若该用户的工作空间成员关系最初由域规则自动或手动加入时创建，则一并移除，并立即撤销相关权限。若用户在绑定域规则前已经是该工作空间成员，则工作空间成员关系会保留。工作空间所有者不会因移除域绑定而被移出工作空间。

## 历史个人对话

若历史账号被加入一个锁定个人空间的域，且个人空间仍有对话，用户登录时会看到“处理个人对话数据”弹窗。用户可以：

- **下载副本**：将全部历史个人对话及消息导出为可移植的 Aivory ZIP；下载不会移动或删除服务端数据。个人空间锁定期间，只有这组专用数据接口可以读取待处理的个人对话。
- **迁移到工作空间**：仅当该成员拥有“创建工作空间私有对话”权限时可用。根对话及其内联子对话会一起迁入指定工作空间，普通成员不可见，但工作空间所有者和管理员仍可按管理权限查看。
- **暂时忽略**：关闭登录提示但不处理或删除数据。侧栏头像菜单会保留“数据管理”入口，之后点击会重新打开同一弹窗。

迁移会保留消息、对话附件、置顶/收藏和归档状态。个人项目与个人知识库不能跨空间引用，因此对应关联会被清除。迁移完成后不会自动移回个人空间。若管理员禁止该成员创建工作空间私有对话，服务端会拒绝迁移，此时只能下载副本；前端是否显示迁移按钮不构成权限依据。

## 停止、删除及更换负责人

- **停止自动加入**：规则创建后默认运行；只有平台管理员在编辑规则时手动打开“停止自动加入”，才会停止后续账号自动入组。已有域用户的绑定和空间限制继续生效。
- **删除域规则**：停止后续自动入组，解除该规则下所有用户的绑定及个人空间限制。已有工作空间成员关系和数据保留。页面会先显示影响说明并要求确认。
- **修改匹配域名**：可以增删规则的匹配域名，只影响后续自动加入和注册验证，不改变已有域成员。一个匹配域名不能同时属于多条规则。
- **修改目标工作空间**：为避免静默迁移已有成员及数据，创建后不可修改；需要更换时删除原规则，再创建新规则。
- **删除工作空间**：空间只要仍被任一域规则引用，就不能删除。须先删除引用它的域规则，避免用户被锁到不存在的空间。
- **在平台后台更换管理员**：进入工作空间详情，点击“更换管理员”，只能选择当前空间成员。新负责人获得所有者和管理员身份，原负责人降为普通成员，其他管理员角色保留。角色更新和管理员邀请撤销在同一事务完成，并记录操作的真实平台管理员。
- 工作空间所有者原有的“转移所有权”流程保持其既有语义：转移后原所有者继续保留管理员身份。

## 数据与验证

服务启动时通过现有幂等迁移机制创建 `registration_domains`、`registration_domain_matches` 和 `domain_users`，同时支持 SQLite 和 PostgreSQL 的建表语法。旧规则会自动将原域名回填为第一条匹配记录；三张表均已加入完整备份和恢复的依赖顺序。

新增测试覆盖多域精确匹配、重复匹配域冲突回滚、旧规则匹配回填、跨域账号搜索与批量原子加入、成员移除与工作空间成员关系来源判断、历史用户组保留、个人对话提示/忽略/迁移权限、根对话与内联对话完整迁移、锁定期间专用下载接口、全局与域规则验证策略组合、OAuth 验证豁免与多域规则入组、初始用户组、事务回滚、停止及规则删除、用户例外、修改邮箱后保持限制、锁定成员退出及入组限制、直接资源访问和伪造空间参数、同会话解除限制、非成员不能接任管理员，以及前端空间切换限制。
